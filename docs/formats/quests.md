# Flags, the journal and the quest atlas (roadmap 1E)

The engine code that sets and reads flags is audited in [hardcoded-content.md](../hardcoded-content.md). The port of the flag network, its evaluation and what the engine writes into flags, is in [flags](../systems/flags.md).

The atlas is `QuestIndex` over the imported plugins' records. `aidyn-renewed flag <flag>...` prints what sets, clears and reads a flag, with the nearest dialogue line and where each script is started, from the installed plugins without the ROM. To browse it, use the editor's Atlas tab and flag pages (see [editor](../systems/editor.md)). The atlas shows each flag's setters and readers and each script's nodes, and draws what leads to an item (upstream) or what it leads to (downstream). The index cross-references the dialogue ops, script done and battle flags, map objects, shops, key items, members, the chunks' world map regions, the flag network, the journal and the state flags record. It doesn't record what engine code reads and writes beyond that (battles' boss flags, the cinematics' flags, the world map's pieces reading theirs, the minimaps' and the camp scenes': see [hardcoded-content.md](../hardcoded-content.md)), nor the scripts code starts, such as the help menu and the death scenes. The importer reads those tables and names the flags they hold, such as "Brenna is in the party", as the flag records' labels (`FlagLabels` in `AidynRenewed.Rom/Quests`), and the editor shows these names.

- **Derived flags:** each has a kind (logic, value or count), an operation, an operand and its inputs. Logic flags are AND, OR, exactly-one (EOR), none (NOT) or "inputs as bits equal the operand" (MSK). Value flags compare the inputs as bits, and count flags compare how many are set, using ==, >, < or !=. Inputs of 0xFFFF are skipped. How they're evaluated is [flags](../systems/flags.md#the-network)'.
- **Engine state as flags:** the calendar, rain and terrain are written into flags 2299–2324, and 2325–2369, the party's best stats and skills, are laid out but never written ([flags](../systems/flags.md#what-the-engine-writes)).
- **The journal:** entry *i* has flag 5556 + *i*, which is "entry *i*'s flag is set". When a flag from 5556 up turns on, the game raises flag 3617 and shows the new-entry notice.
- **Flags nothing sets:** besides those engine code sets ([hardcoded-content.md](../hardcoded-content.md)), 955–958 and 960–963 have no setter but Ehud's underground's secret doors ([maps](maps.md#map-objects-in-the-base-plugin-06)).
- **Reading flags from a checkpoint:** `gameStates` (1.0: `0x800DAF00`) points to the loaded `GameStateFunnel`. Its word at +8 points to the 8-byte flag entries, and each entry's byte at +6 is the flag's current value.
